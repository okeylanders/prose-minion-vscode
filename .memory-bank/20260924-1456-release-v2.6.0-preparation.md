**Date:** 2026-09-24 (CDT)

**New version:** `v2.6.0` (minor feature release)

## Changes since v2.5.0

- PR #116 (merged as `6aa03ab5`) adds provider-reported cache-read counts beside processed tokens in Workshop response headers. Missing reports stay hidden; explicit zero remains visible. Cache-write counts and the prompt-token denominator are available in the detail text. OpenRouter normalization, parallel Dictionary usage, multi-call aggregation, persistence, and response rendering all carry the values.
- Repeated standard or fast Dictionary saves now use `<word>.md`, then `<word>-2.md`, `<word>-3.md`, etc. No-overwrite rename protects earlier entries and concurrent saves.
- The two earlier post-tag commits record the v2.5.0 GitHub and Marketplace releases; they add no v2.6.0 runtime behavior.
- No v2.6.0 dependency changes. This release observes cache usage; it does not add provider-specific cache settings or change the context bar.

## Compatibility

- Existing Workshop sessions load in v2.6.0. New cache fields are optional in its persisted-session reader.
- A session saved with cache fields by v2.6.0 may be rejected by v2.5.0's strict reader after downgrade. Okey accepted this forward-only limitation; the session codec ADR and changelogs disclose it. This exact downgrade failure occurred in the Development Host, and returning to the cache-capable branch restored the reader.
