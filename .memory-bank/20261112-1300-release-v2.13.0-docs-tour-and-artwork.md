## How the captures were made

The scratch scripts were not committed (`lib.js`, `room.js`, `host.js`, `capture2.js`, `compose.js`, `tour.js`).

- **Harness:** headless Chromium (Playwright) loads this branch's `dist/webview.js` as the Workshop surface, as `docs/pr-reviews/evidence/workshop-reactions-slice-3c-tapback/harness.js` does. A stand-in for `acquireVsCodeApi` records what the tab posts and answers it.
- **State:** one `workshop_session_state` snapshot of a made-up room about the opening of *Alice* (public domain): a reply with a `fixes` offer and a two-option `rewrites` offer, the press and its answer with a three-change file-edit card, a writer message with Jill's reaction, and a reply with a memory proposal. The excerpt carries three planted slips for the fixes to name.
- **Host answers** (fixture data, request ids echoed): model data, the pinned-context list (4 files), the memory-drafts setting, a memory draft, the memory listing (6 memories), the live bookmarks and one bookmark page (2 saved sessions).
- **No model was called.** The header's model name is demo content.
- **Captures:** 2× crops by element box, 0 page errors, each looked at before use. Ring and call-out positions were measured from the same DOM as each crop.
- **Composition:** HTML in the v2.12.0 house style, rendered at 1×, 1252 px wide: 1642, 1969, 900 and 1828 px tall, 228–361 KB.
- **The tour pages** were rendered from the rebuilt bundle at 1240×900 with the real shots: every image loads and every call-out sits on its control.
