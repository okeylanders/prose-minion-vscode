## Key changes

- Workshop now preserves divergent machine-local and portable named
  checkpoints instead of using wall-clock timestamps to choose and overwrite
  one automatically.
- Explicitly opening the named checkpoint promotes it; equivalent checkpoints
  retain normal ordered dual autosave.
- Added the live-verified direct OpenRouter model
  `google/gemini-3.8-flash` to Recommended Models, Assistant, Dictionary,
  Context, Workshop, Conversation Widgets, Category Search, and the manifest
  enum without changing defaults.
