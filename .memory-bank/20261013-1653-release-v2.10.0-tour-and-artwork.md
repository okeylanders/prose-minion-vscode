## How the captures were made

- **Harness:** headless Chromium loads the v2.10.0 `dist/webview.js` with a stubbed `acquireVsCodeApi`. The scratch scripts were `svt-common.js`, `svt-workup.js`, `capture-svt.js`, `capture-dict.js`, and `compose-v2100.js`.
- **Show vs. Tell inputs:** in an excerpt room (the demo market scene), the sheet was opened from Widgets → Show vs. Tell → Open widget. The capture filled in:
  - beat "Mara was afraid of the harbourmaster."
  - close-third POV on Mara
  - must survive
  - Use excerpt

  Generate was then clicked.
- **Show vs. Tell workup:** the harness answered the webview's `workshop_show_vs_tell_generate` token with a `workshop_show_vs_tell_result`. It holds one demo workup in the host's real format:
  - an `svtw-<uuid>` workup id
  - `<workupId>:variant-N` variant ids
  - four groups and five variants

  Variants 3 and 5 were kept, with 5 carried as prose.
- **Sections:** each section was scrolled into view inside the sheet's own scroll body and clipped there. Lifting the sheet's height clamp overflowed the fixed-height dialog, so it was not used.
- **Dictionary:** the sidebar Dictionary tab in Warm Dark, with a `dictionary_result` whose palette is Okey's real "Madder Dye Vat" lookup output, verbatim. That includes the literal `*alizarin*` asterisks his screenshot shows. The README alt text says the palette comes from a real lookup.
