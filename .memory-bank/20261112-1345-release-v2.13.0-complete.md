## Shipped

Workshop suggested file edits and reply edit actions; project memories and
helper-drafted memory sheets; pinned context; bookmark recall; writer and
persona reactions; the two-tab rail and model attribution; four opt-in models;
and a new Workshop tour, README artwork and upgrade notes. Earlier extension
versions cannot open sessions containing the new optional fields; users who
sync sessions should update all machines before opening affected sessions.

Okey confirmed v2.13.0 and reported that the exact VSIX passed local testing.
He authorized the merge, GitHub release and Marketplace publication. The only
change after package generation and before the merge recorded that acceptance
in the release checkpoint, which is outside the VSIX.

## Dependency audit

The public npm audit reported **22 affected package entries: 2 critical,
6 high, 7 moderate and 7 low**. Production-only audit identified DOMPurify;
its critical and high advisories require modes the extension's string
sanitizer does not enable. Critical Handlebars and the remaining high and
moderate packages are development-only. This is a reachability assessment,
not a claim the vulnerable versions were patched. The per-package table and
limits of test coverage are in the preparation checkpoint.

The checkout is on main. Retain local and remote release branches; no branch
or tag deletion was requested.
