## Release analysis

- Published predecessor: v2.8.0 on 2026-10-04.
- 140 commits after the tag, including nine merged PRs: #124–#127 and #129–#133. #124 exports transcripts; #125–#133 build and integrate saved-session recall. Two user-facing features warrant a minor release.
- Export offers Markdown, JSON, or styled HTML from the Sessions menu. It projects the full visible ledger and writes numbered files under `prose-minion/exports/`.
- Recall adds `transcript.catalog`, `transcript.search`, `transcript.read`, and `transcript.todos` for other named sessions in the accepted workspace. Privacy, bounds, context delivery, and save/reopen paths have focused automated tests and PR reviews.
- Existing sessions load. Older exact-key readers reject sessions containing new recall values; Git-synced machines should upgrade together.
- Changelog and README lacked these features before preparation. They now lead with v2.9.0; no Workshop startup notice or artwork change is claimed.
