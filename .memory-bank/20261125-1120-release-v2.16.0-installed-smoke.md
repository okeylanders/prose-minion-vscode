## Observations from the live models

- GPT-5.4 Mini guessed a partial-results button label from help search excerpts. After reading the full section it gave the correct control. It also said it could turn off organizing on a Workshop request. Workshop always includes the organizing allowance. The sidebar offers the toggle.
- GPT-4.1 Mini first omitted the draft folder from a Git lookup. The extension refused the shortened path. Providing the full catalog path, including the drafts folder, yielded the correct commits and comparison.
- The displayed search prices are estimates. Actual organization billing was not independently verified. Credentials were entered through Settings and cleared from the isolated test instances.
