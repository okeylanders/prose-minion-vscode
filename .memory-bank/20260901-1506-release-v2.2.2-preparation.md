## Light Review

- CRITICAL: none.
- WARNING: a pre-existing in-memory reread race can replace a newer excerpt if
  the user mutates the excerpt during asynchronous authorization/file reads and
  the disk content changed. The new unchanged-content provenance repair is
  version-guarded, and the general race was not introduced by this patch.
  Action: defer a compare-and-swap hardening follow-up; non-blocking for this
  patch because it requires concurrent user mutation and never writes to disk.
- INFO: relocation recovery requires exactly one workspace root, lexical
  containment, and per-segment symlink checks; repaired absolute provenance
  remains host-private at the webview boundary.
- INFO: a POSIX filename containing a literal backslash can be interpreted as
  nested path segments during relocation recovery, but the result remains
  confined to the workspace and is not a security escape.
