# Release Preparation: v2.1.0

**Date:** 2026-07-28
**Branch:** `release/v2.1.0`
**Previous release:** v2.0.3
**Release type:** Minor

## Release summary

v2.1.0 promotes the Workshop beta: a persistent editor-tab Writers' Room with
persona hosts/guests, retained multi-turn conversations, visible tool sidecars,
bounded capabilities, context/excerpt workflows, durable sessions, and
optional web research. It also adds the current model-catalog entries and
release-candidate UI/polish.

## Documentation and versioning

- Bumped root, core, and VS Code extension manifests plus `package-lock.json`
  from 2.0.3 to 2.1.0.
- Promoted the prepared Workshop sections in the consumer and detailed
  changelogs.
- Refreshed the Marketplace README's What's New section for the Workshop beta.

## Verification

- `npm test -- --runInBand`: 139 suites, 1,518 tests, 1 snapshot passed.
- `npm run test:coverage`: 139 suites, 1,518 tests, 1 snapshot passed.
- `npm run typecheck`: core, webview, and extension projects passed.
- `npm run build`: production bundles and resource staging passed; bundle
  sentinels passed. Existing webview-size warnings remain.
- Initial VSIX package: `prose-minion-2.1.0.vsix`, 187 files, 11.09 MB.
- Manual Workshop smoke passed after reloading the Extension Development Host.

## Audit and review

- Compatible `npm audit fix` updated seven tooling resolutions including
  PostCSS, `linkify-it`, `fast-uri`, and `brace-expansion`.
- Remaining `npm audit --audit-level=high` findings require a breaking ESLint
  10 migration and are development/packaging tooling only. Tracked in
  `.todo/tech-debt/2026-07-28-eslint-10-audit-remediation.md`.
- Focused release review found no critical or release-blocking issues. The
  Workshop configuration manifest, opt-in web-research disclosure, resource
  boundaries, and VSIX contents were checked.
