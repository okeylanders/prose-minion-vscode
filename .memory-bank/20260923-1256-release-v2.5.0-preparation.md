## Release analysis

- The latest public GitHub release is v2.4.0. `origin/main` is an ancestor of the previously published `feat/model-explorer-release-date-groups` branch; this release branch was created from that feature branch to include its validated work without changing `main`.
- Three commits followed the v2.4.0 tag before release preparation: the v2.4.0 completion note, Model Explorer and GPT-6 additions, and dictionary provider-error diagnostics. No pull requests were merged to `main` after v2.4.0.
- No breaking changes or default-model changes. Category Search retains its separate curated catalog; the new Aion storytelling models are in shared writing-tool pickers.

## Changes

- Added GPT-6 Luna, Luna Pro, Sol, and Sol Pro to shared and Category Search model choices.
- Added Aion 3.5 Mini and Aion 3.5 to shared Assistant, Dictionary, Context, Workshop, and Conversation Widget model choices. Their live OpenRouter endpoints advertise 262,144 context tokens, 32,768 maximum output tokens, and temperature, reasoning, and tool-calling support. Both are available through AionLabs at the published prices recorded in the detailed changelog.
- Added parameter-count tags and a By Release Date view to Model Explorer. Aion's collaborative systems carry `multi-model system` tags.
- Preserved upstream OpenRouter details in failed dictionary results and Prose Minion output-channel diagnostics.
- Synchronized root, core, extension, and lockfile versions; updated consumer and engineering release docs.
