# Proposed v2.14.1 release preparation

**Date:** 2026-11-17 (America/Chicago). **Branch:** `release/vNEXT-2.14.1`. **Base:** `3f99e733`, after release v2.14.0. **Proposed version:** v2.14.1, a patch for Workshop native tool-call recovery; awaiting Okey's confirmation before version references and the final branch name are changed.

## Scope and review

PR #267 repairs blank replies when a Workshop persona emits native capability calls, notably with web research enabled. Recognized calls pass through existing Workshop validation; malformed, oversized or unknown calls are not executed, and unanswered calls can enter a bounded retry. Whole and streaming transport, capability mapping, authorization boundaries, and follow-up corrections have focused coverage. A focused release review found no new blocker; the previous malformed-argument finding was fixed and re-reviewed. The author reported a live pass for operation names and a string-encoded multi-file path, but real-array emission, memory.read and all provider shapes are not independently verified. A literal filename that itself parses as a JSON array has a documented translation ambiguity; the re-review records its escape hatch and confirms path authorization still applies.

The consumer changelog, README and detailed changelog have a small proposed 2.14.1 entry, currently marked Unreleased. Version manifests and lockfile remain at 2.14.0 until confirmation. No breaking change identified.
