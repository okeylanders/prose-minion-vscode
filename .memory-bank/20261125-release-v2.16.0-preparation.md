## Opus or Fable handoff

Use `release/v2.16.0` for the README and Workshop What’s New modal. Both changelogs have the release facts under **2.16.0 – Unreleased**. [Marketplace changelog](../apps/vscode-extension/CHANGELOG.md) · [Detailed changelog](../docs/CHANGELOG-DETAILED.md)

- Passage Search can find the same gesture or motif across drafts even when the words differ. The sidebar shows the estimate before Run and links verified quotes back to the source. The optional organizer’s citations jump to the matching passages.
- A Workshop persona can propose the same search, including narrowing a configured group to selected drafts. The writer approves the run. A complete result can go back to the persona automatically. An incomplete or stopped result waits for the writer to send it.
- Workshop personas can close to-dos in the room or in saved sessions, with a receipt and Undo. They can compare a chapter against its Git history and propose context paths for the writer to review and apply. Settings has its own **Suggest from my folders** entry point.

The design files are the Marketplace README and the Workshop notice component. The notice revision currently reads `v12`. The registry maps screenshot names to files under the extension’s `assets/workshop-notices/`. The previous release’s design record describes the existing tour and screenshot conventions.
