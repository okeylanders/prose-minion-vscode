# Release Preparation: v2.1.1

**Date:** 2026-08-03
**Branch:** `release/v2.1.1`
**Previous release:** v2.1.0
**Release type:** Patch

## Release summary

v2.1.1 refreshes the curated OpenRouter model catalog. Meta Muse Spark 1.1 is
available in both Recommended Models and Category Search; Qwen3.8 Max is
available in Recommended Models. Existing defaults and saved selections remain
unchanged.

## Documentation and versioning

- Bumped the root, core, and VS Code extension manifests plus `package-lock.json`
  from 2.1.0 to 2.1.1.
- Added a v2.1.1 consumer changelog entry, detailed technical changelog entry,
  and Marketplace README highlight.
- Updated `docs/RECOMMENDED_MODELS.md` in the feature commit with descriptions
  and OpenRouter links for both models.

## Verification

- `npm test -- --runInBand`: 139 suites, 1,518 tests, 1 snapshot passed.
- `npm run test:coverage -- --runInBand`: 139 suites, 1,518 tests, 1 snapshot
  passed; 76.58% statements, 67.62% branches, 76.52% functions, and 76.78%
  lines.
- `npm run build`: production extension and webview bundles passed, resources
  were staged, and bundle sentinels passed. Existing webview-size warnings
  remain.

## Audit and review

- `npm audit` reports no critical issues and three high-severity transitive
  findings: `brace-expansion` through ESLint, VSCE, and Tailwind tooling;
  `fast-uri` through Ajv used by VSCE/Webpack tooling; and `undici` through
  VSCE's Cheerio dependency. These are development/packaging paths, not
  extension runtime dependencies. No remediation is applied in this focused
  catalog release.
- Focused review found no critical release blocker.
- **Warning:** Category Search is documented as non-thinking-only, while the
  new Muse entry is described as a reasoning model. Confirm its intended
  token/reasoning behavior during the manual smoke test; no functional
  incompatibility was established from this change set.

## Remaining steps

1. Commit and push release preparation.
2. Build the VSIX and perform a manual smoke test.
3. After explicit approval, merge to `main`, tag `v2.1.1`, create the GitHub
   release, and publish to the VS Code Marketplace only if explicitly requested.
