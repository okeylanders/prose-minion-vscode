## How the captures were made

The scratch scripts were not committed: `tools/build-readme.test.ts`, `harness.js`, `compose.js`, and `tour.js`.

- **States (real host output).** The builder is adapted from `docs/pr-reviews/evidence/lightbox-slice-5a2-visual/tools/build-boards.test.ts`. It ran as a temporary copy under `packages/core/src/__tests__/` and was deleted after.
  - It drives the production `LightboxHandler`, `LightboxReadingHandler`, `LightboxBoardsHandler`, `LightboxPassageHandler`, `LightboxService`, runner, `LightboxBoardStore`, and `LightboxBoardLibrary` through `lightboxBoardsHarness`, over a memory file system.
  - The text is ¶1–¶8 of *Alice* Chapter I, the worked examples' text, saved as `Chapters/01-down-the-rabbit-hole.md`.
  - **Story:**
    - Oct 26: the chapter is boarded, groups A and B are read, and the board is named "First read".
    - Oct 28: the writer spells out the heading's numeral ("Chapter One"), the only edit, so the board is new.
    - Then every call is read except the Opinion. The Opinion is off because the harness's stand-in Opinion text says it is a test.
    - A separate fresh workspace boards the same text measured only: the `measured` state.
  - **Passages:** answers for every paragraph range and the top eight words were recorded, so pins answer from host output.
- **Provider:** each group answers with its worked example, verbatim. The log reports 129 quotes checked and 0 withheld; group D withholds two claims.
- **Model:** the recording reports the placeholder `provider/model-v1`. The harness shows it as `anthropic/claude-sonnet-5.5`, whose list price the stub catalog's $3 / $15 per million tokens matches, so "Read by claude-sonnet-5.5" and the estimates agree. README alt text calls the readings demo content.
- **Harness:** headless Chromium (Playwright) loads the v2.12.0 `dist/webview.js` as the Lightbox surface, adapted from the 5A.2 harness.
  - The clock is fixed at Oct 28, 2026, 3:00 PM UTC.
  - The harness answers the tab's estimate, shelf, and passage requests from the recording, echoing request ids.
  - Each state is captured at 2× once two frames match, with a page error and unanswered-passage check: 0 errors.
- **Composition:** HTML in the house style (`#170f09` ground, JetBrains Mono pills, `#211a0f` panels framed `#3d2d1f`, Inter captions `#b3a28c` / `#e6d6bf`), rendered at 1×, 1252 px wide.
  - The composites are 1422, 1895, and 997 px tall; `lightbox-readings.png` is 510 KB.
  - Rings are overlays in the composition, not edits to the captures.
- **Notice shots:** straight 2× crops of the same captures (1520×520 and 582×544).
