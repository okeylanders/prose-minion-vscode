## Findings

1. **P1 — A catalog entry can read the wrong file.** [ConfiguredResourceLookup.ts:107](https://github.com/okeylanders/prose-minion-vscode/blob/2d60e6364045a897331fa61ebb57a281bc26031a/packages/core/src/application/services/ConfiguredResourceLookup.ts#L107) short-circuits on a browse hit, before checking the authoritative listing. With case-distinct files in one group or identical relative paths in separate workspace roots, the inventory lists both but read can resolve the other file or arbitrarily choose the first. History and Read in reader share the resolver. Check the authoritative candidates before returning a browse hit for a catalog-addressable pair; preserve exact identity where unique, and refuse ambiguous pairs rather than guessing.
2. **P2 — An explicitly empty native match list widens scope.** [WorkshopNativeToolCallTranslator.ts:231](https://github.com/okeylanders/prose-minion-vscode/blob/2d60e6364045a897331fa61ebb57a281bc26031a/packages/core/src/application/services/workshop/WorkshopNativeToolCallTranslator.ts#L231) emits no match elements for `matches: []` (also for a provider-supplied stringified empty array), so catalog treats the filter as omitted and inventories the entire group, or all groups if group is absent. Reject supplied empty lists rather than widening; omitted filters and nonempty matches should retain their intended behavior.
3. **P2 — Escaped names do not round-trip from catalog to Passage Search.** [workshopReplyPassageSearch.ts:131](https://github.com/okeylanders/prose-minion-vscode/blob/2d60e6364045a897331fa61ebb57a281bc26031a/packages/core/src/utils/workshopReplyPassageSearch.ts#L131) preserves entity text in the group match attribute, while the catalog's XML text parser decodes it. An ordinary folder name such as `Arts & Crafts` has different parsed patterns when represented with the same XML escape. Decode bounded XML attribute values before validation and verify catalog-to-search parity for ordinary escaped folder names.
4. **P2 — A previously approved two-pattern search can silently become partial.** [PassageSearchScopeFiles.ts:313](https://github.com/okeylanders/prose-minion-vscode/blob/2d60e6364045a897331fa61ebb57a281bc26031a/packages/core/src/application/services/passageSearch/PassageSearchScopeFiles.ts#L313) uses the narrowed union without surfacing a zero-match pattern on a replan. A saved Workshop card that originally matched A and B can later estimate and search A alone if all B files have vanished, while the result still names A and B. Preserve generic engine union semantics where required, but recheck Workshop scope at estimate/Run, or make the narrower scope explicit and ask for fresh consent. The resolver behavior was exercised; the potential complete/auto-send presentation was traced statically.
5. **P2 — Overlapping aliases duplicate evidence and budget in one read.** Wire-level `(group,path)` deduplication is intentional, but two distinct valid catalog pairs can now map to one file. [WorkshopResourceReadFiles.ts:81](https://github.com/okeylanders/prose-minion-vscode/blob/2d60e6364045a897331fa61ebb57a281bc26031a/packages/core/src/application/services/workshop/WorkshopResourceReadFiles.ts#L81) resolves both, then loads and manifests both. The same file can consume the output budget twice and appear as two pieces of evidence. Deduplicate or mark aliases redundant by resolved host identity before loading.
