## Findings

1. **P2: A dispatched organizer failure can still look fully metered.** `PassageSearchModelOrganizer.ts:183–192` treats non-abort rejection as no usage entries. A request can already have gone out before the resulting HTTP 200 body fails to decode or has no choices (`OpenRouterClient.ts:206–230`; `AgentRunEngine.ts:946–971`). With two metered reads and a mocked unreadable organizer response, both inline and explicit organize made three calls but reported two, $0.02, 10 cached tokens and 6 cache-write tokens as complete. Carry a typed indication of dispatch or admit conservatively when dispatch is possible. Count an admitted unknown entry and suppress complete cost/cache totals; distinguish known pre-dispatch outcomes. No actual charge was inferred. The parallel pre-existing read-side convention merits a follow-up check. Separately, `PassageSearchPassUsage.ts:35–39` reconstructs partial read counts from answered and cancelled when there is no read usage total: one valid unmetered read, one malformed unmetered reply and one metered organize counted 3 inline vs. 2 explicit (no combined cost/cache either way).
2. **P2: Sample fitting can refuse an admissible request or sharply shrink coverage.** `PassageSearchOrganizeRequest.ts:178–202` reserves the widest displayed count even for the first row. In a synthetic 60-row case with only row 1 viable, the fully rendered singleton was 1,724 tokens and the fitter returned no request at 1,724. Size each candidate with its actual next count and keep the final whole-message check. Separately, the greedy walk doesn't guarantee the monotonic coverage stated at lines 142–146: a synthetic 64-row case gave five rows at 1,803 tokens but two at 1,804. Define the intended coverage tradeoff; test it rather than guaranteeing a property of the ordering that the fitted sample doesn't have. The fitter did not exceed the limit in these checks.
3. **P2: A possessive inside a single-quoted span can let fabricated quoted text survive.** `PassageSearchOrganizeChecks.ts:96–103,149–165` can take the possessive apostrophe as the close, then ignore the actual closing mark. Given the source “The sailors watched the water.”, an organizer quote of “The sailors’ map was blue” using curly single outer marks survived in claim, title, and headline: only “The sailors” was checked. This is not reliably fail-closed. Resolve the delimiter or reject ambiguous quotations when the entire displayed quotation cannot be grounded. Keep positive controls for genuine possessives, ordinary contractions, and supported nested punctuation.
