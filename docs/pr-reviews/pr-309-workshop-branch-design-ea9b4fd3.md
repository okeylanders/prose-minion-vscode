# PR #309 · Workshop branch-in-new-tab design review

Independent Astra 6.2 review of `ea9b4fd35e9bf4cbcfb893adb8968f7df64bba9b` against `0d0659f9d4240be7a0d495597d135cd66a380e8b`. **Request documentation changes.** The proposed destination and source preservation make sense; record the existing save/refusal and recovery guarantees explicitly. This is not a runtime review or merge authorization.

1. **P2 · Define what “saved source” means.** [The acceptance criteria](https://github.com/okeylanders/prose-minion-vscode/blob/ea9b4fd35e9bf4cbcfb893adb8968f7df64bba9b/.todo/features/feature-workshop-branch-in-new-tab/README.md#L25-L34) distinguish unnamed rooms and active runs, but a named association does not prove the room was saved. Keep the refusal for pending or failed source saves and for a missing, unreadable or externally changed named checkpoint. Before a successful branch save, a refusal must create no file or panel and must not force-save the source. This preserves the contract checked by [the existing coordinator](https://github.com/okeylanders/prose-minion-vscode/blob/f074d9a8f40ad9d436c3e2f8974ac2ee6cb3863f/packages/core/src/application/services/workshop/WorkshopSessionPersistenceCoordinator.ts#L1281-L1305).
2. **P2 · Specify what happens if the branch saves but its tab does not open.** Distinguish a failed write from a successful named save followed by an open failure. In the latter case keep the one saved branch available from Sessions, report that outcome, allow reopening by the saved session ID without creating another branch, and leave no blank tab or provisional claim. The source file, draft, history and ownership remain unchanged. [The previous coordinator already distinguished these outcomes](https://github.com/okeylanders/prose-minion-vscode/blob/f074d9a8f40ad9d436c3e2f8974ac2ee6cb3863f/packages/core/src/application/services/workshop/WorkshopSessionPersistenceCoordinator.ts#L1305-L1337).

Also clarify that the saved branch ID and filename are unique; existing sibling branches can share a display title. The restored content from a writer turn can be a widget configuration, not just composer text. Test pointer and keyboard via the existing action, confirming the native editor opens in the source group and takes focus. Keep feature #37's routing-key checks separate from the branch-destination guarantee.

**Scope.** The two-file diff is design documentation only. [PR CI](https://github.com/okeylanders/prose-minion-vscode/actions/runs/45752328651) passed; no independent runtime tests were run. [Implementation #310](https://github.com/okeylanders/prose-minion-vscode/pull/310) landed separately on the epic during review and already records both the committed-source guard and the named branch available after an open failure. These findings ask #309 to document those guarantees; they do not assert defects in #310 or clear the epic for main.
