**Verdict:** Hold for two P2 gaps. [Exact-head CI passed](https://github.com/okeylanders/prose-minion-vscode/actions/runs/44977422812).

1. **P2: A read refused before provider dispatch can still be counted as an unmetered provider call.** The organizer excludes both typed pre-dispatch reasons, but `PassageSearchService.ts:328–348` only special-cases missing credentials and records `context-window-exceeded` as unknown usage and a provider failure. `AgentRunEngine.ts:917–948` throws this typed refusal before provider admission. This can occur when a held sidebar plan built without a known model window runs after the catalog learns the window; the sidebar consumes the held plan (`PassageSearchRoute.ts:214–228`). In a pinned offline run with a plan built on an unknown window then a known 16,384-token window, a large read was refused locally. Only the short read and organizer reached the mocked provider, each fully metered ($0.01, 5 cache reads and 3 cache writes); both inline and explicit paths reported 3 requests, 24 tokens, and no cost/cache total. Separate local preflight from admitted unknown usage and provider failure streak. If failed calls and not-sent calls remain separate UI categories, give explicit reconstruction a dispatched count rather than treating every failure as a dispatch (`PassageSearchPassUsage.ts:35–39`).
2. **P2: Single-quote grounding still approves a checked prefix while displaying unchecked words.** `PassageSearchOrganizeChecks.ts:103–112` ignores a closing mark preceded by ordinary space and can reset the span on an ASCII elision after a possessive. In pinned validator checks, the canonical possessive now correctly failed, but with the same synthetic source a single space before the final closing mark let the invented continuation remain in claim, title, and headline. A straight-apostrophe elision inside a quote likewise left an invented middle unchecked. When punctuation is ambiguous, check the entire candidate quotation or withhold it rather than accepting a partial match. Preserve ordinary contractions, bare possessives and supported nested punctuation with positive controls.

**Confirmed improved:** A genuinely dispatched unreadable reply now contributes an unknown usage entry in both run modes; cost/cache are withheld, and explicit reconstruction accounts for failed reads. The prior P1 remains closed: the inline pass is tied to the run-owned engine. Exact-fit singleton now succeeds at 1,724 tokens and refuses at 1,723; an independent render-every-candidate oracle agreed for 186 bounds, including mixed Unicode. The documented spread-first policy may choose fewer rows at a higher allowance, no longer claims monotonic coverage, and did not exceed the bound.

**Integration:** Reviewed against the epic containing #294. Verification used head-pinned source, actual accounting/fitting/validation helpers and a stubbed provider/preflight boundary. No live provider, native VS Code host, clipboard, or real credential rotation tested. No merge performed.
