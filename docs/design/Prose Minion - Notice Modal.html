Welcome to the Workshop beta

The Workshop is a conversation space for working with a host, focused guests, and analysis instruments. It is still settling, so this short tour points to the controls that matter most. You decide when to send a message, run a tool, attach context, or apply text; Prose Minion never changes project files on its own.

In the modal
  • 1Close (×) — dismisses this run only; the tour returns next launch.
  • 2Don't show again — one checkbox, applies to all six notices.
  • 3Dots / arrows — jump between notices in any order.
2 / 6 · Setup

Start with an open project folder

Open your writing project folder in VS Code. Then use the Prose Minion Settings gear in the sidebar to tell the extension where character sheets, locations, project notes, drafts, and manuscript chapters live. For the best results, split drafts and manuscripts into individual chapter files so assistants can find and read the right material without treating a whole novel as one document.

Where to do it
  • 1File → Open Folder… — point VS Code at the project root before anything else.
  • 2Settings gear — top-right of the Prose Minion sidebar; opens Project Resource Locations.

Then follow How to configure your project below.

3 / 6 · Primer

Choose a host, then invite guests

Every session has a host. Jill is the default, but you can choose a different host before the conversation begins. You can also invite guest personas with focused specialties such as rhythm & pacing, continuity, dialogue, or voice & POV; they work beside the host, never replace it. For especially distinctive persona voices and strong judgment about when to read project resources or run another analysis, try Gemini 3.6 Flash. GPT-5.6 Terra and GPT-5.6 Sol are also excellent choices.

Where to look
  • 1Host chip — set before the conversation begins.
  • 2Model picker — Gemini 3.6 Flash, GPT-5.6 Terra, GPT-5.6 Sol.
  • 3Talking to — who is currently in the room.
  • 4Invite guest — add a focused specialist beside the host.
4 / 6 · Primer

Set the room's conversation style

Find the diamond-shaped Conversation Controller chip in the composer controls. The Behavior tab sets how host and guest personas respond: mode (how opinionated), expression (how much they say), and depth (how far they read into things). Those choices are per-session, stay visible, and never change silently. The About you tab lets you choose how the room addresses you and share a short writer profile as background context. In Advanced, you can let personas research the live web when it helps; their replies show each source as a clickable citation pill. These conversation controls do not apply to direct instrument threads.

Where to look
  • 1Conversation Controller — the diamond chip in the composer bar; the label reads out the current mode.

5 / 6 · Primer

Tools — run them directly, or ask a persona

Run any of the fourteen analyses directly against a pinned excerpt and its report lands visibly in the thread. Or ask your host or a guest to run an isolated analysis on a specific line, variation, or question from the conversation. Just ask: the persona can decide when a tool would help and bring the useful result back into the room. Direct tool runs unlock when an excerpt is set.

Where to look
  • 1Tools — the fourteen analyses; enabled once an excerpt is pinned.
  • 2+ — pin the excerpt and attach project context.
6 / 6 · Primer

Agents can work with your project

With project paths configured, hosts and guests can find and read relevant project files when the conversation calls for them — you do not need to attach every file by hand. They can also use the dictionary, run analyses, and inspect a particular variation without derailing the main conversation. The Widgets browser is a preview of tools still to come; it does not launch widgets yet.

Where to look
  • 1Widgets — a preview browser; nothing launches yet.

Project-file reading depends on the paths set in Project Resource Locations.

Referenced by notice 2

How to configure your project

Prose Minion never guesses at your folder layout. You tell it where each kind of material lives with glob patterns, and every host, guest, and instrument reads from those paths. Three steps, once per project.

STEP 1

Open the project folder

VS Code → File → Open Folder… and select your book's root folder. The extension only sees what is inside the open workspace.

STEP 2

Open Prose Minion Settings

Click the Settings gear in the Prose Minion sidebar and scroll to Project Resource Locations.

STEP 3

Fill in one glob per field

Comma-separate multiple patterns. Patterns are relative to the workspace root; **/* means "everything below this folder".

A well-aligned project

One folder per resource type, one file per chapter — this is the layout the fields below map onto.

Where you enter it — Settings → Project Resource Locations

Eight fields, each with its own hint and example beneath the input.

Values shown are from another project — use the mapping below.

characters/**/*

Split chapters into individual files. Draft and manuscript fields end in *.md rather than **/* on purpose: one chapter per file lets an assistant open exactly the chapter it needs instead of loading a whole novel as a single document.
