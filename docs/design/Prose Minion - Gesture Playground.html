Gesture Playground — the first widget, and the whole spine

Sprint 01's widget, and the proof of the pattern every later one reuses: select a phrase, one model call returns a bounded menu of gesture directions, the writer keeps the useful ones, and the commit lands a visible turn plus a one-shot thread-artifact that rides exactly one turn. Nothing touches the conversation until commit; the chip on the committed turn re-opens the exact draft.

It's interactive: in §1, click Widgets → pick Gesture Playground → generate → select → commit. The chip that lands in the thread re-opens the exact draft (clone-and-recommit). Jill's coral chip shows the persona recommend + prefill path.

What this frame decides
  • Nothing lands until commit. The modal edits a local Draft; Cancel/Esc discards it. Only a commit adds the selected artifact to the room.
  • Persona protocol, minimum viable — Jill's message carries a recommend chip with an optional prefill seed. Launch falls out of recommend; auto-commit is out of scope in Sprint 01.
  • The commit is a normal turn — a visible message plus a one-shot thread-artifact that rides exactly one turn, then becomes ordinary history.
  • Clone-and-recommit. The chip on a committed turn re-opens the exact prior Draft; committing again creates a new turn at the head. The old chip stays as a historical marker — history is never rewritten.
  • This is the template. Show vs. Tell (Spread 04) reuses this rail wholesale and spends its novelty on the control surface instead — which is the cheapest possible way to add a craft widget.

The pre-commit surface

Decisions
  • Input is {targetPhrase, context, characterNotes} — phrase seeds from the editor selection, context auto-pulls from the excerpt, notes are the writer's (or the persona's prefill).
  • Explicit seam — grouping, selection, and counts are deterministic scaffold; the only model hit is the menu generation, on a fast tier. Regenerate re-rolls the cloud; commit never re-runs it.
  • Directions, not replacements — the writer multi-selects directions to keep; the persona still writes the prose. Deliberately ~10× narrower than the Writer's Dictionary.
  • Grouped by where the gesture lives — eyes, face, hands and body, and the reader's read. A taxonomy, not a ranking: no option is marked best.
  • The cloud is thrown away at commit. What rides the rail is a compact, instruction-shaped directive — never the whole exploration.

Clicking re-hydrates the full authoring UI from the persisted Draft — not a dead summary. Try it: this one is live.

Invariants
  • Chip ≠ frame. The chip is webview presentation only; the model never sees it, and it costs zero context.
  • Config, not just output, persists — the full Draft by stable id in WorkshopSessionService, host-side, so the chip re-opens the authoring state.
  • New reserved frames register with the neutralizer in the same change — a persona quoting widget output can't spoof a frame.
  • Never a knob on the participant. No widget touches persona identity, lens, or conversation behavior — only the work.
  • Core stays host-agnostic — host, registry, and widget logic in packages/core; only the composer mount touches the extension.
