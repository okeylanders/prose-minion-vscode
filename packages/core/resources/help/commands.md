# Commands

## Command locations

In the Command Palette, search for Prose Minion and the title. The prose-minion.editorContext menu is the editor's Prose Minion submenu. Menu availability depends on the selection, file type and active view.

| Command id | Title | Where it appears |
| --- | --- | --- |
| prose-minion.assistantSelection | Assistant | Command Palette, prose-minion.editorContext |
| prose-minion.wordLookupSelection | Word Lookup | Command Palette, prose-minion.editorContext |
| prose-minion.openSettingsOverlay | Settings | Command Palette, view/title |
| prose-minion.showOutputChannel | Show Debug Output | Command Palette, view/title |
| prose-minion.openWorkshop | Open Workshop | Command Palette |
| prose-minion.newWorkshopTab | New Workshop Tab | Command Palette |
| prose-minion.reopenWorkshopRoom | Reopen Closed Workshop Room… | Command Palette |
| prose-minion.workshopSelection | Send to New Workshop Excerpt | Command Palette, prose-minion.editorContext |
| prose-minion.addSelectionToWorkshopMessage | Add Selection to Workshop Message | Command Palette, prose-minion.editorContext |
| prose-minion.openLightbox | Open Lightbox | Command Palette |
| prose-minion.lightboxSelection | Open Selection in Lightbox | Command Palette, prose-minion.editorContext |
| prose-minion.openFileInLightbox | Open File in Lightbox | Command Palette, explorer/context, editor/title, prose-minion.editorContext |
| prose-minion.proofreadFlag | Proofread and Flag | Command Palette, prose-minion.editorContext |
| prose-minion.proofreadFix | Proofread and Fix | Command Palette, prose-minion.editorContext |
| prose-minion.clearProofreadFlags | Clear Proofread Flags | Command Palette |
