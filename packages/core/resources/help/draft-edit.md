# Draft Edit

## Proofread

In a Markdown or plain-text editor, select the passage to check, or clear the selection to check the file. Open the **Prose Minion** context submenu and choose **Proofread and Flag** or **Proofread and Fix**. Both commands are also in the Command Palette. Proofread checks spelling, homophones, punctuation, capitalization and spacing. Agreement, tense, person, missing or stray words, inconsistent names and quotation marks can also produce flags. The file supplies narration context even for a short selection. Markup such as front matter, code and link destinations is protected.

**Flag** puts findings in the editor and Problems panel. Use the lightbulb to inspect a suggested replacement or dismiss a flag. **Clear Proofread Flags** clears Proofread findings. **Fix** offers mechanical corrections in one undoable change. By default Refactor Preview opens with the changes unticked. Tick the entries to apply, then choose Apply. You save the edited file yourself. Judgment calls stay flagged.

Use the Proofread model and reasoning settings to choose the model and its reasoning allowance. A model that requires reasoning cannot run at off. The fix review setting controls the preview. Choose a spelling convention for the project or leave it on auto. Add character names and invented words to the Proofread word list to accept those spellings.

## Craft Flags

In the editor's **Prose Minion** submenu choose **Craft Flags**. The confirmation lists the calls, model, words and estimated price. Each enabled category gets a call. Cliché checks familiar phrasing carrying too much weight, register shift checks prose against the chapter's narration, gesture strain checks awkward physical beats, and continuity flags two passages that disagree. A continuity finding links the later detail to the earlier passage.

With a selection in a chapter within the 25,000-word limit, the pass reads the chapter for context and flags the selected passage. For a larger chapter, select a part within the limit to read alone. Findings appear as information under **Prose Minion Craft**. Dismiss an individual note or run **Clear Craft Flags**. Craft Flags leaves the prose in place and has its own findings, independent of Proofread.

Choose categories and reasoning in Craft Flags settings. Light, Standard and Deep set the reasoning budget for each category. Standard is the default and also applies to an older Off setting. A model without reasoning support can still flag the passage. The Craft Flags model follows the Assistant model until you pick a separate one.
