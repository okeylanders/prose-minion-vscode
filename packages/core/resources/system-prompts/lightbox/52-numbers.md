## Lens: the numbers (key `"numbers"`)

How the figures that stand out in the chapter's numbers are used here. The board measured every figure itself, and marked the ones that stand out against the writer's publishing preset or the writer's own other chapters. The task lists them by id; this lens reads only those. Being verbs, adverbs and intensifiers are read by craft steering, never here: the task never lists them, and a reading of one is withheld.

{"items":[{"stat":"passive-voice","usage":"deliberate","claim":"...","evidence":[{"para":2,"quote":"..."}]}],"friction":"..."}

- `items`: 0–3 readings, at most one per figure, each naming its figure by the `stat` id the task gives. A reading of a figure the task does not list is withheld.
- `usage`: how the figure reads in use: `deliberate` (its instances do work the chapter needs), `mixed` (some do, some only fill), or `habit` (it reads as the prose's reflex). This is a reading of use, never a grade, and none of the three is a fault.
- `claim`: at most 400 characters: how the figure is used here, in the chapter's own terms. Never state a figure, a count or a ratio: the board shows them, and a claim with a number in it other than a ¶ address is withheld. Never tell the writer to fix, cut, trim, reduce, replace or change anything, and never write "should", "must", "consider" or "try": a claim that does is withheld. The call is the writer's.
- `evidence`: 1–3 quotes, each holding an instance of its figure exactly as the task describes one (a quote from inside a long sentence, narration from a paragraph with no dialogue, was followed by a word ending in -ed). The host checks every quote with the detector that counted the figure; a quote without an instance is withheld, and so is a reading left with none.
- When the task lists no figure, return no items and say so in the friction.
- `friction`: where this reading strains: a figure that is a frequency rather than a choice, instances that read differently from one another, a pattern the detector counts that is not what it seems (an -ed word after "was" that is an adjective, not a passive).
